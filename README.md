# 朋友到齐，好戏开场 (Party Game Hub) 🎮🎉

> 不用下载，不用注册。一个链接，就是你们的游戏局！
> 支持真人多端极速实时联机（手机/PC 自适应）与硅基流动 Qwen 大模型 AI 陪玩。

---

## 🌟 平台特色

- ⚡ **即开即玩**：基于原生纯粹 Web 技术构建，无需安装 App，手机端、电脑端浏览器无缝自适应。
- 🔗 **一键邀请**：房主建房后自动生成 4 位短房号、一键直达邀请链接与微信/QQ 好友口令。
- 🤖 **AI 陪玩无缝补位**：接入硅基流动（SiliconFlow）Qwen 系列大模型（Qwen3.5-4B / Qwen2.5-7B），朋友缺席时可随时一键召唤 AI 陪玩进房（支持对弈下棋、机智猜词、说词推理、海龟汤主持、大冒险接招与 @AI 互动）。
- 🔌 **实时双向同步**：Node.js + 原生轻量 WebSocket 状态引擎，断线自动重连，低延迟同步棋盘、画布笔画与聊天公屏。

---

## 🕹️ 游戏矩阵

### 1. 🎮 独立图形对弈小游戏 (支持真人对决与 AI 陪玩)
- **你画我猜**：实时同步画布、调色板与画笔工具，手机端全自适应分栏，AI 实时机智猜词与积分榜。
- **五子棋**：双人专属对决，自适应 15×15 棋盘，黑白棋多局轮流换先，搭载连珠攻防启发式 AI。
- **大话骰**：3D 矢量高光骰盅，顺时针喊点加注，一键开牌自动掀盅，全员明牌高亮命中点数。
- **数字炸弹**：动态收缩安全边界，红黄绿紧张度进度条，智能 AI 战术点位试探。
- **谁是卧底**：卧底/平民/白板身份暗牌，防偷看翻牌，AI 个性化发言描述，全员民主投票放逐。
- **海龟汤**：经典情境推理，AI 智能裁判自动判定玩家提问（是 / 否 / 无关 / 关键信息），逐步逼近汤底真相。
- **真心话大冒险**：精选刺激题库，随机轮盘点名，支持在场 AI 替补接题与灵魂拷问。

### 2. 🎭 聚会联机对局舞台 (Party Arena)
- 覆盖 **UNO、狼人杀、阿瓦隆、飞行棋、黑白棋、同频选择、默契刻度、涂鸦传话** 等 10+ 款经典桌游。
- 配备专属 **聚会公共道具箱**：
  - 🎲 物理掷骰子（全员广播）
  - 🪙 抛硬币决先后（正面 YES / 反面 NO）
  - 🎯 随机顺位抽签（防止抢麦抢发言）
  - ⏱️ 60 秒发言倒计时（红白心跳进度条 + 提示音）
  - 💬 实时对局公屏与 @AI 必回互动

## 🚀 快速启动

### 1. 本地运行

```bash
# 安装依赖
npm install

# 配置硅基流动 API Key (可选，已有内置默认 fallback)
export SILICONFLOW_API_KEY="sk-your-siliconflow-api-key"

# 启动 WebSocket 与服务
npm start
```

访问 `http://localhost:3002/` 或通过任意静态 Web 服务器访问前端静态文件。

### 2. 项目目录结构

```text
├── index.html          # 前端核心页面与各类游戏弹窗 DOM 结构
├── styles.css          # 全局样式系统与手机/PC 自适应断点
├── app.js              # 主应用状态管理、弹窗控制与大厅业务逻辑
├── minigames.js        # 各独立游戏引擎（画布/五子棋/大话骰/炸弹等）
├── network.js          # WebSocket 客户端长连接网络层
├── games-data.js       # 游戏元数据、规则及指引配置
├── icons.js            # 矢量 SVG 图标库
├── audio.js            # Web Audio API 合成音效引擎
├── server.js           # 后端 WebSocket 多房间状态同步服务
├── ai-companion.js     # 硅基流动 AI 陪玩驱动管道与双模降级保障
└── package.json        # 项目配置
```
